Garda Digital Forensics Suite 2011 - Version 7

Open operator.html on monitor 1.
Open evidence.html on monitor 2.

Operator keys:
Enter = run current search
Space = open selected/first file
F1 = Nokia filename search
F2 = Nokia match found
F3 = inspect recovered Nokia file/archive
F4 = decomposition search
F5 = private browsing records
F6 = retrieved information found
F = fullscreen
Ctrl+D = hidden director controls

Evidence monitor:
No taskbar/start menu. Floating 2011-style forensic tools open automatically.
Windows can be dragged, resized, minimised, maximised and closed.
